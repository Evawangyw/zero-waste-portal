# 协作者本机配置说明

这份说明给还没用过 GitHub 的人。目标是在自己的电脑上打开和现在一样的「零废弃知识库」网站，并能向 AI 提问。

网站代码在 GitHub 上。问答引擎 WeKnora 不在这个仓库里，要另外安装。两样都装好，提问才可用。

当前要用的仓库只有这一个：

https://github.com/Evawangyw/zero-waste-portal

不要用别的同名仓库。那个旧地址上的内容不是最新的。

## 开始之前：请仓库主人把你加进去

这个仓库是私有的，不邀请就看不到。

仓库主人用自己的 GitHub 账号打开上面的网址，进入 Settings → Collaborators，填你的 GitHub 用户名，发送邀请。你在邮箱或 GitHub 通知里点接受。

你还没有 GitHub 账号的话，先打开 https://github.com/signup 注册一个。记住用户名和密码。

## 1. 安装三个软件

按顺序安装，装完都先打开一次：

1. **GitHub Desktop**（用来下载代码）：https://desktop.github.com/
2. **Node.js**，选 LTS，版本要 20 或更高：https://nodejs.org/
3. **Docker Desktop**（用来跑 WeKnora）：https://www.docker.com/products/docker-desktop/

苹果芯片的 Mac 如果 Docker 弹出 Rosetta 安装失败，点 **Disable Rosetta**，不要反复点 Retry。等菜单栏的鲸鱼图标稳定后再继续。

## 2. 把网站代码下载到电脑

1. 打开 GitHub Desktop，用你的 GitHub 账号登录。
2. 菜单选 File → Clone repository。
3. 选中 `Evawangyw/zero-waste-portal`，选一个本地文件夹，点 Clone。
4. 完成后点 Repository → Open in Terminal。后面的命令都在这个窗口里输入。

Clone 就是把网上的代码复制到你的电脑。以后主人更新了代码，在 GitHub Desktop 里点 Fetch origin，再点 Pull origin，就能拿到新版本。不要在网页上把 ZIP 下载下来当长期副本，那样不容易更新。

## 3. 准备网站自己的配置

网站的登录数据和密钥只放在 `backend/.env`。这个文件不会上传到 GitHub，所以每台电脑都要自己做一份。

1. 把 `deploy/.env.example` 复制成 `backend/.env`。
2. 用记事本或 VS Code 打开 `backend/.env`，改这几项：

```bash
JWT_SECRET=这里换成你自己生成的一长串随机字符
DB_URL=file:../data/app.db
WEKNORA_BASE_URL=http://localhost:8080
WEKNORA_API_KEY=先留着，装完 WeKnora 再填
WEKNORA_KB_ID=先留着，装完 WeKnora 再填
WEKNORA_CHANNEL_ID=先留着，装完 WeKnora 再填
WEKNORA_PUBLISH_TOKEN=先留着，装完 WeKnora 再填
WEKNORA_ALLOWED_ORIGINS=http://127.0.0.1:5173,http://localhost:5173
WEKNORA_WIDGET_BASE_URL=http://localhost
```

`JWT_SECRET` 在终端执行下面这一行，把输出贴进去：

```bash
openssl rand -hex 32
```

Windows 如果没有 openssl，可以先写一串足够长的随机字母和数字，不要用别人的。

密钥不要发到微信群，也不要写进任何文档。

## 4. 启动网站

仍在项目文件夹的终端里执行：

```bash
npm install
npm run prisma:generate
npm run prisma:push --workspace backend
npm run dev:backend
```

再开一个终端，进入同一个项目文件夹，执行：

```bash
npm run dev:frontend
```

浏览器打开 http://127.0.0.1:5173 。能看到基金会介绍，就说明网站已经起来。

每台电脑的登录库都是空的。点「登录」，自己注册一个账号。注册要填姓名、机构、职业、关注议题和手机号。别人电脑上的账号不会跟着代码一起过来。

这时还不能提问。提问要等下面的 WeKnora 配好。

## 5. 安装问答引擎 WeKnora

WeKnora 是另一个软件，版本固定为 v0.8.2。不要改它的源代码。

在终端执行：

```bash
git clone --branch v0.8.2 --depth 1 https://github.com/Tencent/WeKnora.git
cd WeKnora
```

把 `.env.example` 复制成 `.env`。用编辑器打开这个新的 `.env`，确认有这两行，并且后面不是空的：

```bash
SYSTEM_SIGNING_KEY=一串随机字符
SYSTEM_AES_KEY=另一串随机字符
```

可以这样生成后自己贴进去：

```bash
openssl rand -hex 32
openssl rand -hex 16
```

这两把密钥生成后不要再改。然后启动：

```bash
docker compose pull
docker compose up -d
```

浏览器打开 http://localhost 。页面标题应是 WeKnora。这是管理页，不要把这个地址发给普通访客。

## 6. 在 WeKnora 里配模型和知识库

1. 在 http://localhost 注册一个 WeKnora 管理员。这和网站的登录账号不是同一个。
2. 安装 Ollama：https://ollama.com/download 。装好后在终端执行，并保持这个窗口不要关：

```bash
ollama serve
```

另开一个终端，下载两个模型：

```bash
ollama pull qwen3:8b
ollama pull bge-m3
```

3. 在 WeKnora 里新建知识库。初始化时：
   - 对话模型选 Ollama，名称 `qwen3:8b`，地址 `http://host.docker.internal:11434`
   - 向量模型（Embedding）选 Ollama，名称 `bge-m3`，维度 `1024`，地址同样是上面这个
   - 地址不要写成 `localhost`。WeKnora 在 Docker 里，`localhost` 指不到你电脑上的 Ollama。
   - 如果模型列表是空的，说明模型还没下载完。下载完再点「刷新列表」。
4. 添加 ReRank 模型。Ollama 不能做重排。来源选 API，服务商选硅基流动 SiliconFlow：
   - 地址：`https://api.siliconflow.cn/v1`
   - 模型：`BAAI/bge-reranker-v2-m3`（不要选名字前面带 `Pro/` 的，那个收费）
   - 密钥：到 https://cloud.siliconflow.cn 注册后自己新建的 API Key
   - 点「测试连接」，成功后再保存。
5. 建一个智能体，检索范围选这个知识库。在智能体的模型配置里，把 ReRank 选成刚才那个模型。
6. 打开「设置 → 网页嵌入」，新建渠道并绑定这个智能体。允许嵌入的域名填：

```text
http://127.0.0.1:5173
http://localhost:5173
```

7. 记下三样东西，填回网站的 `backend/.env`：
   - 渠道 ID：在嵌入代码里，`data-channel="..."` 中间那一串
   - 发布令牌：以 `em_` 开头
   - API Key：在「设置 → 发布集成 → API 集成」里新建
   - 知识库 ID：在知识库详情里
8. 保存 `backend/.env` 后，关掉正在跑的后端窗口，重新执行 `npm run dev:backend`。

## 7. 怎样算配置成功

1. 打开 http://127.0.0.1:5173 ，注册并登录。
2. 首页只有「向知识库提问」。输入一个问题，点「向 AI 提问」。
3. 右下角出现绿色的问答按钮，并开始回答。
4. 顶部可以打开「资料书架」。索引里还没有正式 PDF 时，会看到占位书，这是正常的。

如果提问出现 `embed session signing key is not configured`，回到 WeKnora 的 `.env` 检查 `SYSTEM_SIGNING_KEY` 是否已填写，然后在 WeKnora 文件夹里重新执行 `docker compose up -d`。

如果出现 `rerank model is not configured`，回到智能体的模型配置，把 ReRank 模型选上并保存。
