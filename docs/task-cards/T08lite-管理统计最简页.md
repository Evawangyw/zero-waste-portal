# T08-lite 管理统计最简页（任务卡）

> 来源：小志 2026-10-05 早指示（试验阶段先看效果，正式图表看板仍是节后 T08）｜ 依赖：T02✅、T07✅ ｜ 派发：2026-10-05

## 目标

给管理员一个能看的统计页 `/admin/stats`：读 `GET /api/admin/stats/summary` 的数据渲染成表。**结构完整、不追求美化、不引入图表库**（节后 T08 再换正式看板）。

## 产出要求

- 路由 `/admin/stats`：非管理员访问显示"需要管理员权限"提示页（不报错白屏）；导航条对管理员显示入口、对普通用户隐藏
- 页面分五块（全部用 summary 接口现成字段，无新后端代码）：
  1. 总览卡：PV / UV / 注册用户数 / 事件总数
  2. 事件分布表：7 类事件各自数量
  3. 检索热词 Top10（带次数）
  4. **零结果词列表**（标"内容缺口线索"）
  5. 下载 Top10 + AI 提问板块（总数/无答案率/已判定/未判定）
- 数据 5 分钟自动刷新或手动刷新按钮（二选一，回报说明选了哪个）

## 验收标准（主控逐条实测）

1. 管理员账号（13800000001）登录后能打开 `/admin/stats`，五块数据与 curl summary 返回一致
2. 普通账号（13900000010）访问看到权限提示而非数据
3. `npm run build:frontend` 通过、lint 零报错
4. 回报附 ls + 截图（无头 Chrome 截 /admin/stats 管理员视角一张即可）

## 边界

- 不加图表库、不做导出、不做筛选（全是 T08 正式版的活）
- 不动后端；frontend 内新增/修改 views 与 router 即可
