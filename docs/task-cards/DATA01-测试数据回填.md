# DATA-01 测试数据回填（任务卡）

> 来源：小志指示（清空私人文件后换公开测试资料）｜ 前置：T09lite 导入工具

## 目标

把「111」知识库（已清零）重新灌成**公开来源的测试资料**，供演示和开发用。

## 步骤

1. **下载公开测试 PDF（10~20 份）**，优先级：
   - ①中文公开政策/报告类（政府官网附件、NGO 公开报告，与零废弃/垃圾分类/环保主题越贴越好）
   - ②下不到中文就用开放学术 PDF（arxiv 等开放获取源）凑数
   - 每份下载后验证是有效 PDF（文件头 %PDF 或能打开），**单份 ≤15MB**，重命名成可读标题
2. **造一份 metadata.xlsx**（列：知识名/知识发布机构/知识发布年份/知识类型/知识领域/文件名）——机构/年份按文件来源如实填，查不到填"未标注"；知识类型统一"测试资料"；知识领域按主题（零废弃/垃圾分类/测试数据…）
3. **用 T09lite 的导入 CLI** 灌进「111」库（KB id=ab5f8c28-1231-4a9e-93b0-a707af652d40，mapping.json 按上面列名配）——**这同时是导入工具的实战检验**
4. 跑 syncIndex 刷新书架索引

## 验收标准（主控逐条实测）

1. 「111」库 total = 导入报告成功数（10~20）
2. 抽 3 份：API 读回 custom_metadata 与 Excel 行一致；书架 /api/docs 能搜到标题
3. 导入报告无"失败"（或失败原因逐条说明）
4. **红线自查**：所有文件来源公开、无任何真实个人信息（这是本卡的立卡原因）
5. lint/tsc 双零；回报附 ls + 导入报告 + 抽样读回 JSON

## 边界

- 下载只从公开渠道（gov/NGO/arxiv 等 HTTP），单源失败就换源，不硬磕
- 禁碰「批量导入测试」库和其它库；禁 git push/禁 Docker/禁动 backend/.env
- ai_ask 零次（本卡不测问答）
