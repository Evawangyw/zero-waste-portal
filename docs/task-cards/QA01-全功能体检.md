# QA-01 全功能自由体检（人的视角找 bug）

> 来源：小志指示（试验阶段把功能测扎实）｜ 性质：测试轮，产出=问题清单

## 任务

**关掉开发者视角，装成一个没读过任何文档的普通用户/队友**，把整个网站从头到尾用一遍，专找"用着别扭/点了没反应/数据不对"的地方。

## 测试路径（全部走一遍，每步记录结果）

1. **新用户**：注册一个全新账号（手机号 13700000NY 段、姓名"体验员NY"）→ 登录 → 刷新页面看登录态保持
2. **游客身份**（退出登录后）：首页点三个示例问题 → 挂件提问各一次 → 书架筛选（年份/类型/主题/机构各试一次+组合）→ 搜索一个真实文件名片段 → 搜一个乱词看"零结果+问AI引导" → 点开详情 → 预览 → 点下载看是否被引导登录
3. **登录后**：同一文件下载成功 → 文件名是否符合"年份-机构-标题" → 再下载一次
4. **管理员**：用 13800000001 登录 → /admin/stats 五块数据 → **重点核对**：你刚才每做一步，对应计数是否 +1（这是"统计真实性"的验收）
5. **边界捣乱**：注册缺字段/错手机号/短密码；搜索空格/特殊字符；未登录直接 curl 下载接口

## 产出

`docs/测试报告/QA01-问题清单.md`：每条问题 = 复现步骤/预期/实际/严重度(P0功能坏了/P1别扭/P2建议)。**没有问题也如实写"该路径通过"**。修 bug 另派单，本卡只测不修。

## 红线

- 提问/下载适度（ai_ask 全程 ≤6 次）
- 禁 git push / 禁 Docker / 禁动 backend/.env / 禁改任何代码
- 落盘自证：报告写完附 ls
