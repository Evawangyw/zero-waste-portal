# T09-lite 批量导入工具（任务卡）

> 来源：规划 v1.1（"后台批量导入功能先行开发"，PRD R13/R14-N2）｜ 依赖：T01✅ ｜ 派发：2026-10-05

## 目标

做一个"Excel 元数据 + PDF 文件夹 → WeKnora 知识库"的一键导入 CLI。**明天老师给真数据时，改一个映射配置就能跑 400 份**，人工零参与。

## 输入设计（对接钉钉表格那五列）

- `inputs/` 目录：一批 PDF/Word 文件
- `inputs/metadata.xlsx`：列名按钉钉表格（知识名/知识发布机构/知识发布年份/知识类型/知识领域/文件名）——**列名→custom_metadata 键的映射写在独立映射配置文件**（`inputs/mapping.json`），真 Excel 列名有出入时只改配置不改代码
- 知识领域单元格可能是"垃圾分类、塑料"多值 → 拆成数组

## 产出要求

- `backend/src/modules/ingest/`：`import.cli.ts`（命令行入口，参数=目标知识库ID+输入目录）+ 解析/上传/元数据写入逻辑
- 流程：读 Excel → 按映射生成 custom_metadata → 逐份调 WeKnora 上传接口（文件+元数据一次写入）→ 失败重试 2 次 → **生成导入报告**（成功/失败/跳过清单，失败原因）
- 幂等：同文件名已存在则跳过（报告标注"已存在"），重复跑不重复导入
- 域名/机构等字段空值 → 写"未标注"（与书架口径一致）
- xlsx 解析用 npm 包（如 xlsx），允许安装依赖

## 验收标准（主控逐条实测）

1. 主控**已备好**：测试库「批量导入测试」ID=`e81b4870-1ba7-48c4-884c-d40a79aee270`；`inputs/files/` 下 2 个样例 PDF（样例文档一/二.pdf）。迷你 Excel（3 行：两行有完整元数据、一行留空值，知识领域含"垃圾分类、塑料"这类多值）**由你自造**放进 inputs/。**导入后该库应有 3 条知识，custom_metadata 逐字段与 Excel 一致**（用 API 读回核对）
2. 重复跑第二遍 → 报告显示 3 条"已存在"，库里仍是 3 条
3. 空值字段落"未标注"
4. lint/tsc 双零
5. 回报附 ls + 导入报告内容 + API 读回的元数据 JSON

## 边界

- 目标库只用主控新建的「批量导入测试」，**禁碰「111」测试库**
- 标签（tags）本卡不碰（API 挂载有坑，元数据"知识领域"已是兜底真源）
- 上传的 3 个测试文件让主控准备还是你自己造都行——内容随便（文本型 PDF 最好），**禁含任何真实个人信息**
