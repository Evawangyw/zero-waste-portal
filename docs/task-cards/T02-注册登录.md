# T02 注册登录（任务卡）

> 来源：规划 v1.1 §6 阶段二 ｜ 依赖：T00 ✅ ｜ 派发：2026-10-05

## 目标

自建用户体系（与 WeKnora 账号隔离）：五字段注册 + JWT 登录 + 路由守卫中间件。

## 需求口径（PRD R01）

- 注册五字段：姓名、所在机构、职业、关注议题、联系电话（全部必填）+ 密码
- 注册页需有"隐私提示+勾选同意"校验（后端校验 consent=true 必传）
- 手机号格式校验；登录态保持 ≥30 天（JWT 有效期 30d）
- 关注议题用多选（数组存 JSON）

## 产出要求

- Prisma `User` 模型（五字段+密码哈希+createdAt）；`prisma migrate dev` 落库（数据库名不变）
- `backend/src/modules/auth/`：`POST /api/auth/register`（五字段+密码+consent 全校验，bcrypt 哈希）、`POST /api/auth/login`（返回 JWT）、`GET /api/auth/me`（JWT 中间件保护）
- JWT_SECRET 从 `backend/.env` 读（已备好，禁写死源码）
- 在 app.ts 挂载 auth 路由（**这是你要动 app.ts 的唯一理由，其他模块不许碰**）
- 下载/提问等"需登录动作"的守卫中间件先做好导出（T04/T06 会用），本卡不接线

## 验收标准（主控逐条实测）

1. `POST /api/auth/register` 缺任一字段返回 400 且报错指明缺哪个；全字段通过返回用户（无密码哈希泄漏）
2. 重复手机号注册返回 409
3. `POST /api/auth/login` 正确密码返回 token；错误密码 401
4. `GET /api/auth/me` 带 token 返回五字段用户信息；不带 token 401
5. 数据库里密码是 bcrypt 哈希不是明文
6. lint/tsc 双零；回报附 ls + 每条 curl 回显

## 边界

- 测试数据用 `13X00000000` 段假号码，测完的测试用户保留（主控要复验）
- 不做前端页面（T05 阶段统一做）；不碰 weknora/、docs/、ask/ 模块
