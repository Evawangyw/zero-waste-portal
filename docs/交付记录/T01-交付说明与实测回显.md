## 3. ⚠️ 对主控「主控已实测的环境事实」的一处修正

卡片第 13 行写「**`done:true` 结束**」。实测**不成立**，已按实测修正：

- 第 2 次 query 抓到的真实首帧就是 `{"response_type":"agent_query","content":"","done":true,...}` ——
  这是**用户消息入队的确认帧**，`done` 只表示"该消息片段完结"。
- 若见 `done:true` 就断流，正文一个字都拿不到（本卡第 1 次 query 就撞上这个坑，输出只有一个空 done）。
- 真正的终止信号是 `response_type: "complete"`（`stop` / `error` 同样终止）。
  依据：WeKnora 前端 `useChatStreamHandler` 只在 `complete` 分支收尾。

事件字段名（从 WeKnora 前端 bundle `useChatStreamHandler-oXYNnf8U.js` 核对，零额度）：
`response_type`（answer / thinking / complete / error / references / stop / agent_query / session_title …）、
`content`、`data`、`id`、`done`、`session_id`、`assistant_message_id`。
