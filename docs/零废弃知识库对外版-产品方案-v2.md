## 3. MVP 边界（按 10 月 8 日已经跑起来的站点重划）

本轮边界内：

1. 未登录：基金会介绍、顶栏「登录 / 注册」、页脚。
2. 注册：姓名、机构、职业、关注议题（多选）、手机号、密码、隐私勾选。缺任一项不可提交。
3. 登录后：首页对话（含历史、思考过程）、资料书架、资料详情（预览 + 下载）、右下角问答挂件。
4. 管理员另见「管理统计」。非管理员打开该地址看到权限提示，导航里没有入口。
5. 演示库是公开资料。含个人信息的测试表已清出引擎，本地索引不得残留。

本轮边界外（v1 有、现在没有，不写成已完成）：

- WorkBuddy 与百炼双平台对照（R10）
- 自建 RAG、查询改写、意图分流（R05-B/C、R06）
- 用户上传与审核（R11）、反馈表单（R12）、后台改文件（R13）
- 可点击的来源卡片、引用编号与卡片一一对应
- 看板导出、机构 / 职业 / 议题分布、来源渠道、近 7 日 / 30 日切换
- 每月《内容缺口清单》文档（零结果词接口还在，页面上这块图表没有）

v1 冲突的现行结论：

- 冲突 A / Q1：按 D-01 关闭。公众链接打开先看基金会，使用资料和提问要注册。这比 v1 建议的「浏览预览开放、下载提问才登录」更严。
- 冲突 B / Q3、冲突 C / Q5：本仓库只交一套，问答引擎用 WeKnora。不再排双平台四套方案。
- Q2 主题枚举：筛选选项来自库内实际取值加计数，不把 v1 文档里的「垃圾分类、塑料、有机固体废物」写死成选项。

## 5. 功能规则（只重写被迭代碰到的）

### 5.1 登录与能看什么（D-01，关闭 v1 Q1）

- 未登录可打开 `/` 与 `/foundation`，两者都是基金会介绍。
- 未登录打开 `/shelf` 或 `/doc/:id`，去 `/auth?redirect=` 原地址，登录成功后回来。
- 未登录不注入问答挂件，右下角不能提问。
- 注册五类信息仍必填，另加密码（8–72 位，超长拒绝，避免 bcrypt 静默截断）和隐私勾选。关注议题多选，词表在 `TOPIC_OPTIONS`：政策倡导、社区实践、教育培训、垃圾分类、减塑替代、厨余处理、绿色消费、其他。
- 手机号：11 位、1 开头、第二位 3–9。重复注册返回「该手机号已注册，请直接登录」。
- 登录态默认 30 天（`TOKEN_TTL_SECONDS`）。刷新页面保持。退出清除本地 token，并拆掉挂件。
- 统计只聚合，不在看板上展示手机号。权限提示页可以显示当前账号手机号，便于核对是不是管理员。

v1「浏览和预览对游客开放」不再执行。QA-01 路径二里「退出后仍能筛书架、预览 PDF」与现行规则冲突，以本节为准。

### 5.2 书架（D-04、P0-1、P2-5）

- 路由 `/shelf`，要登录。
- 有索引时：书按主题分组。主题空则归「未标注」。一行本数随屏宽变化。
- 索引总数为 0 且列表为空时：显示占位书，用于演示筛选和点开。占位书没有详情、不能预览、不能下载。页面写明「占位文字不能当作答案」。正式资料入库后占位书消失。
- 筛选四维：知识类型、发布机构、发布年份、主题。选项来自 `/api/docs/facets`，每项带命中数。
- 同一维多选是「或」，跨维是「与」。可一键清空。
- 排序四种：年份新到旧（默认）、年份旧到新、标题、最近更新。空年份排在有年份之后。
- 搜索框对原文件名、可读标题、标题做包含匹配。空格不拆词：`建模 试题` 不会拆成两个词。`%` 和 `_` 按字面量，不当通配符。纯空格当成没搜。
- 分页默认 20 条，最大 100。`page` 小于 1 回落第 1 页。乱写的 `sort` 回落 `year_desc`。
- 只有用户提交搜索才记 `search`。翻页、改排序、浏览器前进后退不另记一次检索。
- 条数以接口 `total` 为准。不在页面上写死「共 42 条」（QA-01 P2-5）。首页只用这个总数判断库是不是空的。

### 5.3 主题筛选的匹配规则（QA-01 P0-1）

v1 只要求「筛了就要命中」。QA-01 的实测是：下拉里「测试领域（1）」，`GET /api/docs?tag=测试领域` 返回 0。

现行规则：

1. 主题存在 `topics` 列，格式如 `["测试领域"]`。匹配时用 `JSON.stringify(主题)` 的字面量做包含，这样主题是「塑料」时不会误中「塑料污染」。
2. LIKE 的首尾 `%` 保持通配。只转义用户输入里的 `\`、`%`、`_`。禁止把整个模式（含 `%`）再转义一次。
3. 查询参数 `tag`、`topic`、`topics`、`tags` 都表示主题，取并集去重。这是为了避免拼错参数名时静默变成「不筛选、返回全部」。
4. 其他认不出的参数名仍忽略，不因此让整页 400。
5. 值为「未标注」时匹配空主题，不拿这个词去 LIKE。

验收仍用 QA-01 的原例：`tag=测试领域` 命中那 1 条；年份 + 机构 + 类型 + 主题四维一起筛也命中这 1 条。数据已在 DATA01 清库后换掉，这条验收依赖当时的测试行；规则本身不随数据作废。

### 5.4 统计口径（QA-01 P0-2、§4.2、P2-8、P2-9）

事件仍是这 7 个：`page_view`、`search`、`preview`、`download`、`ai_ask`、`register`、`feedback_submit`。`upload_submit` 没有，因为上传未做。

改过的触发规则：

- `page_view`：只在路径变化时记一次。只改书架的 query（筛选、搜索、分页）不重复记。首次进入要记。
- `preview`：同一资料 id 只记一次。自动打开预览和再点「在线预览」不记第二次（QA-01 §4.2）。
- `ai_ask`（挂件）：挂件确认已经收到这条问题（`message_sent`）才记。点击了但被上游丢掉的不计（QA-01 P0-2）。用户直接在挂件输入框里打字发出去的，也记。
- `register`：只在注册页提交成功时由前端埋点。直接调注册接口的账号进用户表，但不增加这条事件（QA-01 P2-8）。看板「注册用户」看用户表，「注册」看事件，两者可以不相等。
- `download`：前端埋点一次，后端 `DownloadLog` 另记一行。两条都保留。页面对两者的差额只陈述数字，不写「有接口被直连」（QA-01 P2-9）。

无答案率 = 已判定里的无答案数 / 已判定数。已判定为 0 时比率写 0。挂件路径拿不到回答证据时记为未判定，不把它算进无答案率。

看板不展示个人联系方式明细。管理员每 5 分钟自动刷新，也可手动刷新。点检索词去书架，点文件名打开资料。

### 5.5 问答（D-02、D-03、D-05、D-06、P0-2、P1-1、P1-2）

两条入口，规则分开：

**首页对话（登录后的 `/`）**

- 输入框 + 发送。没有历史时给出 3 个示例问题：清单式「零废弃领域有哪些相关政策？」、场景式「社区厨余堆肥活动怎么设计？」、政策原文式「生活垃圾分类工作有哪些考核要求？」。有历史后示例问题不再占位。
- 正在回答时发送按钮处于加载态，再次点击不并发第二问。
- 空问题提示「请先输入你的问题」。超过 500 字拒绝。
- 库内总数为 0：不请求模型，助手回复「库内暂未收录正式资料，所以不能回答。」这一轮仍留在页面上。
- 有资料：请求 `POST /api/ask`，正文按流式追加。思考过程单独一块，标题「思考过程」。
- 回答结束后写入该账号的历史。刷新后拉取最近 80 条消息（一问一答各算一条）。历史只属于当前用户。
- 流中断：页面保留已收到的正文，并补「回答中断，请再试一次」。能存则把这一轮存进历史。
- 本页不渲染来源卡片，也不把「引用了 N 篇文档」当成可点出处（QA-01 P1-2 的处理是取消这个承诺，不是补上链接）。

**右下角挂件（登录后全站）**

- 标题为「零废弃知识库助手」（QA-01 P1-1）。
- 书架零结果时按钮「试试问 AI」。有搜索词则预填「关于「{词}」，知识库里有哪些相关资料和政策依据？」没有搜索词则用已选筛选项或默认政策问题。
- 上一条还在生成时，新问题进入队列，收到上一条已被挂件接收后再发下一条。90 秒无确认则放行，避免队列卡死（QA-01 P0-2）。
- 挂件里的「引用了 N 篇文档」仍然点不开。这是引擎 v0.8.2 的能力边界。产品文案不得再写「答案带出处」。

对外说明以基金会介绍里的这句话为准：「答案只依据库内资料生成，资料里没有的会直说没有。」

v1「无来源的答案不允许输出」在本轮做不到，因为挂件和首页都没有可核对的来源卡片。验收标准改为：不承诺可点出处；库空时必须拒答。固定题库见 `docs/问答标准题.md`，那是评测记录，不是本轮已交付的产品能力。

### 5.6 详情、预览、下载（QA-01 §4.2、P2-3、P2-4；v1 R08、R09）

- 路由 `/doc/:id`，要登录。QA-01 时游客能打开详情、只有下载才跳登录；现行是整页都要登录（D-01）。
- 详情展示可读信息：标题、年份、机构、类型、主题、文件名、大小、解析状态、来源。缺的维度显示「未标注」，不把这条资料藏起来。
- 能在线看的类型直接出预览流。不能看的给出原因，并保留下载。默认超过 20MB 不内嵌（`PREVIEW_MAX_BYTES` 可配）。
- 预览标题用原文件名，不用 blob UUID（QA-01 P2-3）。解析状态：`completed` 显示「已完成」；不认识的状态原样显示，不猜中文（QA-01 P2-4）。
- 下载文件名：`{年份}-{机构}-{可读标题}.{扩展名}`。缺年份或缺机构就跳过该段，不出现「未标注」，也不出现连续横线。非法字符换成横线，超长截断。
- 未登录时的按钮文案在详情页代码里仍是「下载（需登录）」。由于整页已经要求登录，正常路径下用户看到的是「下载资料」。
- 下载成功提示「已开始下载」。同一文件可以重复下载，每次各记一条下载日志。

### 6.2 登录后首页

### 6.5 管理统计

1. 正在校验登录态（`icon="info"`，QA-01 P2-2）

3. 已登录但 `/me` 失败：提示后端不可用

数据区不再使用 QA-01 时的「① 总览 … ⑥ AI 提问」编号（P2-1 因此不再存在）。现行区块：

- 四个数字：页面浏览、独立访客、注册用户、提问次数
- 站内操作（事件条形图）
- 提问结果（有答案 / 没有答案 / 还没判定）
- 高频提问
- 检索热词（可点进书架）
- 下载最多（可点进资料）

## 7. 内容与数据（QA-01 P1-5、DATA01、P2-6）

- 演示库不得含个人身份信息。2026-10-05 已按授权清掉原测试文件（含学生信息表），并回填 18 份中文公开 PDF。本地书架行数必须等于远端实存行数。只做 upsert、不删本地残留的同步，不允许再用于公开展示。

- v1 的 400+ 全量入库未发生。批量导入工具已具备（Excel + PDF），等正式清单。工具不是前台功能。

## 9. 验收时用哪一版

- 看登录门槛、首页是不是对话、书架是不是书脊、历史是否按账号保留：以本文 §5、§6 和对应源码为准。
- 看主题筛空、连点吞问题、预览双计、坏 JSON、挂件标题、解析状态中文、预览标题：用 QA-01 的问题号对照 §1，不要回到 v1 的笼统验收句。
