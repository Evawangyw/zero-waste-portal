## 2. P1 —— 别扭 / 数据风险

### P1-1 挂件标题露出内部测试名「公众网站挂件-测试」
- **复现**：游客打开首页 → 挂件面板左上角标题
- **预期**：`GET /api/embed/config` 里配的 `title: "零废弃知识库助手"`
- **实际**：面板显示 **「公众网站挂件-测试」**（WeKnora 渠道名）。配置里的 `title` 没生效（官方 loader v0.8.2 大概只认渠道名）。基金会对公众的站点上写着"测试"，很扎眼
- 证据：`docs/shots/QA01/p2i-sequential.png`、`p2e-page-now.png`

### P1-2 承诺"答案带出处"，实际一个链接都点不到
- **复现**：首页 → 问任意示例问题 → 看回答里的「引用了4篇文档」
- **预期**：能点开看引用的原文
- **实际**：挂件 iframe 里 `querySelectorAll('a')` = **空数组**；「引用了N篇文档」是个不可展开的按钮。首页三处文案都写着"答案带出处"，兑现不了
- 说明：官方 v0.8.2 挂件本身没回调，可能属上游能力缺失，但**这是我们自己首页写的承诺文案**，要么给出处要么改文案

### P1-3 非法 JSON 请求体返回 Express 默认 HTML 错误页（还泄露内部报错）
- **复现**：`curl -X POST localhost:4000/api/auth/register -H "Content-Type: application/json" -d '{oops'`
- **预期**：和站内其它错误一样，返回统一信封 `{"success":false,"error":{...}}`
- **实际**：返回 **400 + 一整页 HTML**（`<title>Error</title>` + `<pre>SyntaxError: Expected property name or '}' in JS...`）
- **影响**：① 破坏 API 契约一致性；② 把内部解析器报错原文吐给客户端；③ 前端 `trackJsonErrorHandler` 只挂在 `/api/track` 上，其余接口的 body 解析错误没人接管

### P1-4 挂件 token 挂掉时，首页还照样显示"AI 助手已就绪"
- **复现**：连续提问一段时间后打开任一页面，看控制台
- **预期**：token 换不到就降级提示，用户能知道"AI 现在用不了"
- **实际**：控制台 `[WeKnora] failed to load token Error: token endpoint HTTP 502` + WeKnora `429 Too Many Requests`，**但首页状态文案仍是「AI 助手已就绪，点右下角 💬 打开」**，用户点下去没反应
- **已排除是代码缺陷**：带白名单 `Origin: http://localhost:5173` 直连 `GET /api/embed/token` 连打 6 次，**6/6 全 200**。那次 502 是上游 WeKnora 限流引起的**瞬时**故障（不带 Origin 时返回 403 `origin_not_allowed` 是设计如此，不是 bug）
- **真问题**：**没有降级提示**。上游一抖动，用户只会觉得"这站坏了"

### P1-5 知识库里混着无关的真实个人信息，还被当成"引用"发给公众访客
- **复现**：游客在首页问任意示例问题 → 看 AI 回答内容
- **预期**：知识库只放零废弃政策与实践资料
- **实际**：回答里把 **「顺丰莲花助学项目学生信息登记表（涉及广西隆安、内蒙古巴林左旗、云南镇雄、云南龙陵等地的学生信息）」**、**「顺丰莲花助学项目班服尺码统计」** 当作命中文档引用出来，还给了"点击预览"的入口
- **性质**：**数据治理问题，不是代码 bug**，但测试库是要往生产搬的——测试库里躺着一批含真实学生信息的表格，等于公开站点挂着个人信息源。**建议单独派数据清洗单**（本卡只记录，不动）

**唯一失真：preview 重复计数（P0-2 的同源问题，另立一条）**

- **同一次预览行为被记 2 次**，preview 口径虚高一倍，直接污染"详情页→预览→下载"漏斗

- 建议修单：`DocDetailView` 的自动预加载与按钮点击二选一埋点，或用同一个 `preview` 事件 + 去重标记
